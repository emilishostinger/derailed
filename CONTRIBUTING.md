# Contributing

See [docs/contributing.md](docs/contributing.md) for the development setup, the tests,
and the conventions this codebase follows.

Two rules worth knowing before you write anything:

- **Comments explain why, not what.** If something is written a surprising way, the
  comment says what went wrong when it was written the obvious way.
- **No em dashes.** `bun run lint` fails on one. Use a comma, a colon, a full stop, or
  brackets.
